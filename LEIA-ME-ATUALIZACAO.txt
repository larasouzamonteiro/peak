PEAK — ATUALIZAÇÃO: SÓ O QUE MUDOU (visual novo, nov/2026)
====================================================

Este ZIP tem SÓ os arquivos que mudaram ou são novos (veja a lista no fim).

COMO ATUALIZAR
1. Copie a pasta "peak" deste ZIP POR CIMA da pasta do projeto
   e escolha "Substituir os arquivos no destino".
   ATENÇÃO: não apague a pasta front/img do projeto (as imagens estão lá).
   Nenhum arquivo de senha (config.js, emailConfig.js, .env) vem no ZIP.

2. BANCO: rode UMA vez o arquivo  database/avisos.sql
   - no Aiven (banco projetopeak) e
   - no MySQL do computador (troque a linha USE para  USE peaklocal; )
   Ele só CRIA a tabela "avisos". Não apaga nada.
   NÃO rode o banco.sql de novo (ele apaga o banco inteiro).

3. Teste no computador (node app.js) e depois mande para a Square Cloud
   do jeito de sempre.
